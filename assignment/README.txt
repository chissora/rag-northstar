Pakiet zadania rekrutacyjnego LLM / RAG.

1. Przeczytaj Zadanie_rekrutacyjne_LLM_RAG.docx.
2. Dokumenty źródłowe znajdują się w katalogu documents/.
3. Rozwiązanie powinno działać lokalnie/on-premise bez płatnego API. Rekomendowany LLM: Qwen3 4B przez Ollama; inne bezpłatne lokalne modele są dozwolone.
4. Model embeddingowy również powinien działać lokalnie i zostać krótko uzasadniony w README rozwiązania.
